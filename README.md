One word describing our Wi-Fi: **Ghosted**. Home Wi-Fi ghosts you — full bars one second, gone mid-sentence the next, back again like nothing happened. Funny at once, true to how home Wi-Fi actually behaves, and a fresh angle on a familiar annoyance. It works as a network name with no context needed.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

This writes the single word to `entry.txt` inside the output directory (7 bytes, no trailing newline), deterministically, with no arguments, no network, and no randomness.
